# Analyse, Classification et Génération de Scripts de Films

Ce projet explore l'analyse, la classification et la génération de scripts de films à partir d'un large corpus collecté et enrichi. Il inclut des approches supervisées et non supervisées pour la classification, ainsi que des modèles avancés pour la génération de texte, tels que les Transformers.

## Contenu du projet

- **Classification** : Approches multi-label et multi-classe pour catégoriser les scripts selon leurs genres.
- **Génération de texte** : Utilisation de modèles comme GPT-2 pour produire des scripts cohérents.
- **Analyse exploratoire** : Étude des particularités linguistiques des scripts et des tendances sémantiques.
